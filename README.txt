latent_skeptic_meta
===================

Private, permanently. The session transcripts in here contain full tool
output, local paths, keys-adjacent commands, and infrastructure detail.
Never public, never mirrored.

The tool is latent_skeptic/ (submodule, pinned). Each directory under
experiments/ is one experiment: its question, ledgers, records, results,
and the transcript of the session that drove it, side by side. Sessions
that drove more than one experiment sit at the root. INDEX.txt maps
sessions to experiments and dates.

To answer "how was this done": ledger first, records second, transcript
last. To start a new experiment: copy PROMPT.txt's checklist, nothing
else is prescribed.

# Language contract - append to any prompt whose output a person will read

Write for a reader who has never seen this project. Do not use code names,
stage numbers, arm labels, acronyms, or field names from the files as words:
say what a thing is in plain words first, and only where needed for lookup
add the code in parentheses. Numbers stay exact. As simple as possible, but
no simpler: where a plain word would lose precision, keep the term and
define it at first use.

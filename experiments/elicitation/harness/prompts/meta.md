# Standing suffixes - applied verbatim

Mechanisms, from the retro evidence: the first blocks a mismatch from
collapsing into the nearest answer, so it surfaces as a question instead.
The second sets a compression floor, forcing definitions where codes would go.

1. To any elicitation, review, or discussion prompt:

   "Do not propose any solutions until the problem has been discussed as
   thoroughly as it can be without proposing any."

2. To any prompt whose output explains or summarises:

   "Express this as simply as possible, but no simpler."

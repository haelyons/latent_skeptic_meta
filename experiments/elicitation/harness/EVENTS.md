# Events - when things fire

| event | fires | inputs |
|---|---|---|
| post-endpoint | prompts/elicit.md | new records BESIDE the design's filed predictions |
| pre-build | latent_skeptic triage on the prospective design | design text as claims |
| pre-writeup | regenerate prose from records, never patch; prompts/contract.md applies | records only |
| post-draft | prompts/elicit.md (draft BESIDE records), then gates/ | draft + records |
| post-compression | gates/ rerun on the compressed text | compressed text |
| any launch | write a provenance stub before running | command + inputs |

The pairing column is the point: an object is never sent alone. Questions form
where two things sit side by side; one thing alone yields a summary.

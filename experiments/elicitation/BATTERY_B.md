# Rerun B — same pilot, one substitution (filed before any output exists)

The six arms of the first pilot are rerun exactly: same slices (C4, C6, M2 in
the retro scratchpad, same cutoffs), same structure, same word caps, same
model. One change only, appended to every arm prompt and to the cross-arm
note that will follow:

  LANGUAGE CONTRACT: write for a reader who has never seen this project.
  Do not use code names, stage numbers, arm labels, acronyms, or field
  names from the files as words - say what a thing is in plain words
  first, and only where needed for lookup add the code in parentheses.
  Numbers stay exact.

Why this and nothing else: the first pilot's outputs got denser in coined
codes the more record/claim text an arm held in context (codes per 1000
words: 4.4 with raw rows only, up to 40.1 with designs and triage records;
the final conversation answer reached 55.8, the observation file 67.5).
The codes were minted by the pre-registration/triage layer itself
(REF, SELFQ, OTHERM, packaging - all first appear in DESIGN files of 14 Aug).
The intervention substitutes words for codes at the reporting boundary and
changes nothing about what is read or measured.
